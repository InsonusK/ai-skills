# Problem
The import path of a generated module follows the path of its proto file, so the annotations' modules are top-level packages - `google.api` and `protoc_gen_openapiv2` - whatever folder the contract's code is generated into ([generated-code-inside-the-package](library/architecture/python/vp-grpc-api-in-python.skill/adr/generated-code-inside-the-package.md)). The descriptor of the contract refuses to load without them.

[[#googleapis-common-protos and a generated package]]
- Owner decision, 2026-10-26.

# Searched variants

## googleapis-common-protos and a generated package

**Selected.**

### Description
`googleapis-common-protos==1.75.5` provides `google.api.annotations_pb2` with its type stubs, as it does for every Google client library. `make proto-gen` compiles `third_party/proto/protoc-gen-openapiv2/options/*.proto` - the files the dotnet catalog vendors - into `src/protoc_gen_openapiv2/options/`, with `__init__.py` files and `.pyi` stubs; `packages.find` installs it beside `todo`.

### Benefits
- Google's maintained package for `google.api`, which other libraries (grpcio-status) share, so no second copy of the `google.api` modules exists.
- The openapiv2 modules are generated by the pinned `grpcio-tools` like the contract's own code: always loadable by the pinned `protobuf`.

### Costs
- A second top-level package in the application's distribution; a library installing the same name would clash.

## Python code without the openapiv2 annotations

### Description
`make proto-gen` compiles the Python code from a copy of the proto file with the `openapiv2_*` options cut out; the spec is still generated from the full file.

### Benefits
- No second top-level package.

### Costs
- The descriptor the service serves (reflection) differs from the published contract; the cutting is a text edit of the proto file that a new option layout breaks.

## The protoc-gen-openapiv2 package of PyPI

### Description
A third-party package (unionai-oss) with the openapiv2 modules.

### Benefits
- Nothing to generate.

### Costs
- One release, 2022, generated by an old protobuf: no guarantee it loads with the pinned protobuf 7, and no maintainer to follow the grpc-gateway releases.
