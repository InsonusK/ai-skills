# todo

The base plateau in Python with the gRPC API, its HTTP form, and the PostgreSQL and unit of work
variation points attached: one proto contract (`docs/integration/api/todo/todo.proto`) served over
gRPC on :9090 and over HTTP on :8080, the lists of items kept in PostgreSQL behind one generic
repository over SQLAlchemy and asyncpg, the schema in Alembic migrations. Every command runs in a
unit of work: `ImportItems`, which adds its titles with nested `AddItem` commands, keeps all of
them or none; it has no entry point here, its scenarios send it. The application needs a database:

| rpc | HTTP | Shows |
|---|---|---|
| `PlanItems` | `POST /v1/items/plan` | body `*`, 200 |
| `AddItem` | `POST /v1/lists/{listId}/items` | `insert`; a taken title is 409, a database down 503 |
| `ListItems` | `GET /v1/lists/{listId}/items` | `select_by(ItemsOfList).order_by(ItemPosition).all()`; no rows is 404 |
| `ClearList` | `POST /v1/lists/{listId}/clear` | a deprecated method: 501 / `UNIMPLEMENTED` |

```bash
export DATABASE_DSN='postgresql://todo:todo@localhost:5432/todo'
make init       # once: a virtual environment with the package and its dev tools
make migrate    # bring the database up to the latest migration (todo-migrate, /app/migrate of the image)
make migration NAME=add_item_due_date   # a migration from the changed rows; needs the database at the latest one
make run        # serve gRPC on :9090 (reflection on) and HTTP on :8080 (Swagger UI at /swagger/)
make proto-gen  # regenerate src/todo/gen/api/, src/protoc_gen_openapiv2/, todo.swagger.json
TEST_DATABASE_DSN='postgresql://postgres@localhost/postgres' make test   # every scenario, each on a database of its own
make lint       # the type check (mypy --strict)

curl -X POST localhost:8080/v1/lists/home/items -H 'Content-Type: application/json' -d '{"title":"buy milk"}'   # 201
curl localhost:8080/v1/lists/home/items                                                                       # 200
grpcurl -plaintext -d '{"listId":"home"}' localhost:9090 todo.v1.ItemsService/ListItems
```

| Setting | Default | Meaning |
|---|---|---|
| `DATABASE_DSN` | required | the database, a URL asyncpg reads: `postgresql://user:password@host:port/name` |
| `MIGRATE_ON_START` | `false` | apply the migrations before the entry points start: only for a deployment pinned to one instance |
| `TEST_DATABASE_DSN` | required by `make test` | the PostgreSQL the scenarios create and drop their databases on, a URL |
| `GRPC_LISTEN_PORT` | `9090` | the port of the gRPC API |
| `GRPC_REFLECTION_ENABLED` | `false` | serve gRPC server reflection |
| `HTTP_LISTEN_PORT` | `8080` | the port of the HTTP form |
| `HTTP_BASE_PATH` | (none) | the prefix the service is published under; the spec's `basePath` carries it |
| `HTTP_API_DOCS_ENABLED` | `false` | serve `/openapi.json` and Swagger UI at `/swagger/` |
| `LOG_LEVEL` | `info` | `debug`, `info`, `warn`, `error` |

| Package | Layer |
|---|---|
| `src/todo/main.py` | composition root: the database, the unit of work over it, the repository, the service over it |
| `src/todo/migrate.py` | the migration job |
| `src/todo/api/grpc`, `src/todo/api/http` | the two entry points of one contract; `http/pipeline/proto.py` reads and writes the generated messages as proto-JSON |
| `src/todo/api/core/entry`, `src/todo/api/core/rpcstatus` | the runner of the entry points; the table from error kind to code and status |
| `src/todo/gen/api/todo`, `src/protoc_gen_openapiv2` | generated by `make proto-gen`, committed: the contract's code, the openapiv2 annotations it imports |
| `src/todo/command` | the commands, their results and handlers |
| `src/todo/domain/entity`, `src/todo/domain/service` | entities with the error kinds and rule errors; domain services |
| `src/todo/service` | `ItemLists` over the repository: rows in, entities out, outcomes into kinds |
| `src/todo/infrastructure/postgres` | copied, never edited: settings, `Database`, `Repository`, the selectors, the outcomes, `migrate`, `postgrestest` |
| `src/todo/infrastructure/postgres/tables` | the application's rows, keys, and specifications |
| `src/todo/infrastructure/postgres/migrations` | the application's Alembic migrations; `env.py` is copied |
| `src/todo/infrastructure/postgres/unit_of_work` | copied, never edited: the unit of work, the router of the database's connections |
| `src/todo/command/middleware/unit_of_work` | copied, never edited: the command middleware that ends the unit of the outermost command |
| `src/todo/command/import_items.py` | the sample: `AddItem` once per title |
| `src/todo/log`, `src/todo/config` | the logger and the request id; the base settings |
| `docs/integration/api/todo/` | `todo.proto`, written by hand; `todo.swagger.json`, generated |
| `third_party/proto/` | the annotations the proto file imports, vendored |

Every package keeps its scenarios in `features/` and their steps in `test/` beside its code.
