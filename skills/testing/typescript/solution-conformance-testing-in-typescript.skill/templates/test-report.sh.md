# scripts/test-report.sh

Pure assembly — `$TEST_REPORT_DIR/reports/scenarios/index.html` included, rendered from `$TEST_KIND_DIR/result/scenarios.json` alone — no `npm`/test tooling involved, so this same script (unmodified) also works for the .NET and Python variants of this solution; see [[skills/testing/core/solution-conformance-testing.skill/solution-conformance-testing.skill.md#report-contract|solution-conformance-testing]]. It is duplicated verbatim in each stack solution rather than shared, so each solution stays self-contained and portable on its own.

Copy verbatim to `scripts/test-report.sh` — the same file for every stack that uses scripts: [`assets/scripts/test-report.sh`](../../../core/solution-conformance-testing.skill/assets/scripts/test-report.sh)

`report-template/index.html` is a small static page the project owns (links to `scenarios/`, `tests/`, `coverage/`, `mutation/`) — not generated by this script. It lives outside `.github/` since this solution never owns `.github/workflows/*` — publishing it is a separate CI concern this solution never owns.
