# Installation

## Requirements

- Python 3.10 or later.

## Install

```bash
pip install mylib==1.2.3
```

## Verify

```python
import mylib
print(mylib.__version__)
```

## Troubleshooting

- If `pip` cannot find the package, upgrade pip: `pip install --upgrade pip`.
- On Windows with multiple Python versions, use `py -3.12 -m pip install mylib`.
