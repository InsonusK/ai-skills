# Индекс задач по развитию скиллов процесса разработки

Эта папка содержит артефакты анализа покрытия полного цикла разработки скиллами репозитория `ai-skills`.

## Артефакты

| Файл | Описание | Статус |
|------|----------|--------|
| [`01-process-gap-analysis.md`](./01-process-gap-analysis.md) | Карта процесса от "бизнес ставит задачу" до "код в мастере" и пробелы в покрытии | в работе |
| [`02-missing-skills-backlog.md`](./02-missing-skills-backlog.md) | Детализированный бэклог недостающих скиллов с задачами агента | в работе |
| [`03-skill-development-roadmap.md`](./03-skill-development-roadmap.md) | Поэтапный план проработки скиллов для ИИ-агента | в работе |

## Как читать

1. Начните с `01-process-gap-analysis.md` — там описан полный процесс и выявленные пробелы.
2. Перейдите к `02-missing-skills-backlog.md` — там конкретные скиллы, которые нужно доописать, с указанием задач агента.
3. Используйте `03-skill-development-roadmap.md` для планирования работы агента по созданию новых скиллов.
